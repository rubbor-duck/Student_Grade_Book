# Overview

I am learning how to write classes, functions, read user input and more in java so I can become a more well rounded engineer by learning different langauges.

I wrote a student gradebook program that creates a student from the student class, and can add assignemnts that can be graded for each student.
The gradebook takes in user input to create the student, the assignments, and adding the grades to the student. It also calculates the GPA of the student.

I wrote this software so I can learn how to write classes, functions, and get user input in Java.
I wrote all of this software on my own, with no help from AI or tutorials. I used a website to learn the syntax of Java, but not to write any of the code.
I also wrote this software to give me a refresher on how to implement classes in a program.
